# Documentation

Pick the page for what you want to do.

**Get started**

- [Getting started](getting-started.md): install the mod and the server, connect Claude Code
  or opencode, build from source, fix common problems.

**Play the city**

- [Tools](tools.md): every MCP tool, grouped by job, and how building works.
- [AGENTS.md](../AGENTS.md): the manual the AI mayor follows, with the working pattern and the rules.
- [Game mechanics](game-mechanics.md): demand, taxes, budgets, coverage, level-up, happiness
  and milestones, taken from the game's own code.
- [Expansions](expansions.md): what each DLC adds, and how to check what is loaded.

**Reference**

- [Bridge API](api.md): the HTTP endpoints behind the tools. `scripts/check-api-docs.py`
  keeps this page in sync with the route table.
- [Game API notes](game-api-notes.md): the game classes and methods to use for parts of the
  game that have no tool yet.

**Understand and change the code**

- [Architecture](architecture.md): the components, the threading rule, and why the agent
  builds through the game's own tools.
- [Development](development.md): code map, build and test, and the issue-first workflow.
- [Verification](verification.md): how to prove a change did not break the city.
- [Releasing](releasing.md): versions, the changelog, and cutting a release.

Open work is tracked as [GitHub issues](https://github.com/MinhChien9/cities-skylines-mayor/issues),
not in these pages.
